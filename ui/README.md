# UI Module

The UI module contains the screens and visual elements that users interact with in MeshApp. It presents app and mesh state and passes user actions to the relevant services.

## Responsibilities

- Provide screens for the home view, chats, conversations, network interfaces, profile, and app information.
- Define navigation between screens.
- Provide shared UI components, theme styles, and screen state models.
- Use view models to connect screen actions and displayed state to app services.

This module focuses on presentation. Core messaging, networking, and security behavior is provided by other modules.
