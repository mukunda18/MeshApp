# Logger Module

The logger module provides a shared way for MeshApp components to record application events. Its log entries include a type, source, message, and optional details.

## Responsibilities

- Record informational, warning, and error events through the shared logger.
- Make log entries available to the app's log screen.
- Help developers and users understand events and troubleshoot problems.

This module provides logging support; it does not control how the app responds to a logged event.
